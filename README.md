# K5 AI 3.0 — готовый комплект

Мобильное PWA-приложение-помощник для КАМАЗ поколения К5: облачный Gemini + офлайн-база знаний.

## Что входит
- `public/index.html` — интерфейс для Android/браузера;
- `public/knowledge-base.json` — 20 локальных справочных материалов;
- `public/sw.js` — Service Worker: кэш приложения и базы;
- `server.js` — API-сервер с Gemini, анализом фото, ограничением частоты запросов;
- `.env.example` — пример настроек без секретного ключа;
- `start-windows.bat` и `start-linux-macos.sh` — запуск;
- `Dockerfile` — контейнер для размещения;
- `package.json` — зависимости.

## Модель
По умолчанию `gemini-3.8-flash` — стабильная мультимодальная модель с поддержкой текста и изображений. Наличие модели в API-проекте и бесплатные лимиты зависят от доступности проекта и текущих правил Google. Проверяй актуальные условия:
- Модели: https://ai.google.dev/gemini-api/docs/models
- Тарифы: https://ai.google.dev/gemini-api/docs/pricing
- Создание ключа: https://aistudio.google.com/apikey

На бесплатном тарифе Google может использовать переданное содержимое для улучшения продуктов. Не отправляй VIN, госномер, документы, персональные или конфиденциальные сведения.

## Быстрый запуск на Windows
1. Установи Node.js 22 или новее: https://nodejs.org/
2. Распакуй архив в отдельную папку.
3. Запусти `start-windows.bat`.
4. При первом запуске создастся `.env`. Вставь туда ключ из Google AI Studio в строку `GEMINI_API_KEY=` и сохрани файл.
5. Запусти `start-windows.bat` ещё раз. Скрипт установит зависимости и запустит сервер.
6. Открой `http://localhost:3000` на компьютере.

## Быстрый запуск Linux/macOS
1. Установи Node.js 22+.
2. В папке проекта выполни `cp .env.example .env`.
3. Добавь ключ в `.env`.
4. Выполни `./start-linux-macos.sh` или `npm install && npm start`.

## Как открыть на телефоне
`localhost` на компьютере не означает доступность с телефона. Для постоянной работы на Samsung разверни проект на HTTPS-хостинге (Render, Railway или собственный сервер). В настройках хостинга добавь переменные `GEMINI_API_KEY`, `GEMINI_MODEL=gemini-3.8-flash`, `NODE_ENV=production`. Не загружай `.env` в публичный репозиторий. Открой HTTPS-адрес на телефоне в Chrome/Samsung Internet → меню браузера → «Добавить на главный экран»/«Установить приложение».

## Офлайн-режим
При первом открытии с интернетом Service Worker сохраняет оболочку приложения и `knowledge-base.json`. После этого доступны локальный поиск по справочнику и подсказки без сети. Gemini и анализ фотографий требуют интернета. Для установки PWA нужен HTTPS (кроме localhost).

## Безопасность и ограничения
- API-ключ хранится только на сервере в `.env` или в секретах хостинга.
- Ограничение API: 20 запросов в минуту на IP; тело JSON ограничено 9 МБ; фото — JPEG/PNG/WebP.
- K5 AI не подключается к CAN/ЭБУ и не считывает DTC напрямую.
- Не выдумывает нормативы, номера предохранителей, коды и распиновки при отсутствии подтверждённой документации.
- При красных предупреждениях, проблемах тормозов/рулевого управления/пневматики — безопасно остановиться и обратиться за техпомощью.
- Не используй приложение и не читай экран во время движения.

## Проверка после запуска
- Открой `http://localhost:3000/api/health`: ожидается JSON `ok: true`; `configured` станет `true` после добавления ключа.
- В приложении отправь тестовый текстовый вопрос.
- Затем отправь фото значка панели.
- Открой справочник, найди «EBS».
- После первой загрузки включи авиарежим и повтори поиск по базе.
